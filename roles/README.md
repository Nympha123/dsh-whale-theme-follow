# roles/ · 放角色图的地方

把角色图（`png` / `gif` / `apng`）丢进这个目录，然后：

```bash
node install-role-image.mjs --from-dir roles
```

文件名去掉扩展名就是**显示名**（例如 `华小科.png` → 显示名「华小科」）。

> **本目录默认被 `.gitignore` 整体忽略**（只保留这个 README）。
> 角色形象通常是第三方素材，使用者手上的图往往无法举证授权状态，所以默认不入库。
> 想随仓库分发，请先确认你拥有该图的权利，再在 `.gitignore` 里为该文件加一条 `!` 例外并提交，
> 同时在仓库根目录的 `NOTICE.md` 里补上来源与许可。详见 `NOTICE.md`。
